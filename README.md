# One Task at a Time

A minimal Chrome New Tab extension designed to help you stay focused on **one task at a time**.

Instead of opening a blank new tab full of distractions, this extension displays your current task, active project, to-do list, local weather, and current location on top of a beautiful Unsplash background.

## Features

- 🎯 Focus on your **Current Task**
- 📁 Display your **Current Project**
- ✅ Simple **To-do List**
- 📍 Automatically shows your **Current Location**
- 🌤️ Displays **Current Weather**
- 🖼️ Beautiful **Unsplash** background images
- ⚡ Lightweight and distraction-free
- 🌐 Replaces Chrome's default New Tab page

## Installation

> This extension is currently **not published** on the Chrome Web Store.

### Install locally

1. Click **Code → Download ZIP**
2. Extract the ZIP file.
3. Open Google Chrome.
4. Navigate to **chrome://extensions**
5. Enable **Developer Mode** (top-right).
6. Click **Load unpacked**.
7. Select the extracted project folder.
8. Open a new tab — you're all set!

## Why I Built This

I wanted a clean and distraction-free New Tab page that reminds me of the **one most important task** I should be working on instead of showing bookmarks, news feeds, or dozens of open tabs.

The goal is simple: **focus on one thing, finish it, then move on to the next.**
